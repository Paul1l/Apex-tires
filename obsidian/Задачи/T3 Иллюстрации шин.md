# T3 Иллюстрации для каждого наименования шины

**Цель:** заменить одинаковую заглушку «TYRE» уникальным изображением каждой шины.

**Решения:** [[Решения]] D2, D4, D5.

**Контракт `lib/tire-illustration.ts`:**
- `renderTireIllustrationSvg(input): string`
- `tireIllustrationDataUri(input): string`
- `tireIllustrationAlt(input): string`
- вход: `brand, model, season, studded, runflat, width, profile, diameter` + необяз. `xl, tags`.

**Требования:** вид качественной шины (3/4 или сбоку), рисунок протектора по сезону/типу (летняя, зимняя, шипы, всесезонная, A/T), параметры от хеша бренда+модели, надписи на боковине по дуге, бейдж сезона; экранирование текста, без скриптов и внешних ссылок, ≤ 20 КБ, детерминированность; фото товара в приоритете; подпись «Иллюстрация»; диски не трогать.

**Разрешённые файлы:** `lib/tire-illustration.ts`, `components/tire-illustration.tsx`, функция `ProductArt` в `components/storefront.tsx`, правила `.product-art*`/`.art-*`/`.product-modal-art*`/`.tire-illustration*` в `app/globals.css`, `components/product-details-page.tsx`, `server/tests/tire-illustration.test.ts`, `server/tools/export-tire-illustrations.ts`, строка `images:tires` в `package.json`.
**Запрещено:** другие файлы, типы, API, lock-файл, коммиты.

**Проверка:** lint, typecheck, test (включая новые тесты), скриншоты каталога desktop/mobile, быстрого просмотра, корзины; контактный лист 8 иллюстраций; минимум 2 итерации визуальной доводки.
