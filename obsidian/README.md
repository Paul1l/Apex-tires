# Хранилище Obsidian проекта APEX WHEELS

Откройте папку `obsidian/` как хранилище (Obsidian → Open folder as vault).

- [[Реестр задач]] — все задачи со статусами и владельцами.
- [[Решения]] — журнал принятых решений.
- `Журнал/` — хронология работы по дням: что сделано, кем, с какими проверками.
- `Задачи/` — карточка на каждую задачу.
- `Отчёты/` — полные отчёты исполнителей (аудит, проверки).

Правило ведения: каждое событие (старт задачи, сообщение исполнителя, блокер,
изменение контракта, приёмка) записывается в журнал дня и в карточку задачи.
Записи ведёт руководитель; исполнители сдают отчёты, руководитель переносит их
сюда. Время — UTC.
