# APEX WHEELS

Премиальная SPA-витрина интернет-магазина шин и дисков с отдельной админкой, фильтрами по размеру и автомобилю, регистрацией, корзиной и подготовленным API обмена с 1С.

## Запуск

```bash
pnpm install
pnpm dev
```

Магазин: `http://localhost:3000`  
Админка: `http://localhost:3000/admin`

Демо-администратор:

- Email: `admin@apex.local`
- Пароль: `Apex2026!`

## Что работает в демо

- подбор шин и дисков по параметрам;
- подбор по марке и модели автомобиля;
- фильтры, сортировка, поиск, избранное и сравнение;
- корзина и оформление заявки;
- регистрация и вход;
- отдельная адаптивная админка;
- создание и редактирование товара;
- загрузка изображения товара из админки;
- импорт/экспорт каталога в JSON;
- API-контур интеграции с 1С;
- SQL-схема базы данных.

В демо-режиме пользовательские изменения сохраняются в `localStorage`, чтобы интерфейс был полностью интерактивным без внешних credentials. Серверная схема рассчитана на Cloudflare D1 и автоматически используется API 1С после добавления binding `DB`.

## База данных

Основная миграция: `database/schema.sql`. Drizzle-схема: `lib/db/schema.ts`.

Перед production:

1. Создать D1-базу.
2. Выполнить `database/schema.sql`.
3. Добавить D1 binding с именем `DB` в deployment environment.
4. Задать secret `ONEC_SHARED_SECRET`.
5. Перевести auth/catalog repositories с demo-adapter на D1.

## Интеграция с 1С

Спецификация доступна в `public/1c-integration.md`. Основные методы:

- `GET /api/1c/health`
- `POST /api/1c/import/products`
- `POST /api/1c/import/stock-prices`
- `GET /api/1c/orders/export`

## Production checklist

- подключить D1/R2 для каталога и изображений;
- заменить demo-auth на серверные сессии с Argon2id;
- задать секреты окружения;
- подключить эквайринг, СДЭК/Деловые Линии и уведомления;
- добавить юридические реквизиты, оферту и политику;
- наполнить каталог реальными фото из админки или 1С.
