# Импорт товаров и применяемости

Шаблоны находятся в `docs/examples/products-import.csv` и
`docs/examples/fitments-import.csv`. Первая строка описывает поля, вторая явно
помечена как неактивный пример и должна быть удалена перед рабочим импортом.

## Безопасный процесс

1. Администратор загружает CSV через защищенный server-side endpoint.
2. Парсер ограничивает размер файла, кодировку UTF-8, число строк и длину полей.
3. Каждая строка преобразуется в объект и проверяется runtime-схемой.
4. Валидные строки обрабатываются транзакциями небольшими пакетами.
5. Ошибка одной строки не отменяет корректные строки.
6. Ответ содержит `received`, `created`, `updated`, `failed` и ошибки с номером
   строки без stack trace или секретов.

Публичный CSV endpoint намеренно не создан: до реализации серверной
admin-аутентификации загрузка файлов создала бы небезопасный способ изменения
каталога. Сейчас рабочий импорт доступен через защищенный и версионированный
JSON API 1С; CSV-шаблоны фиксируют будущий контракт ручного импорта.

## Товары

`external_id` и `sku` — стабильные идентификаторы. `condition` принимает `new`
или `used`. Для б/у товара конкретный комплект хранится отдельно от модели в
`used_product_lots`, а его реальные фотографии — в
`used_product_lot_images`. `old_price` необязателен и не используется для
скидки, если он меньше или равен текущей цене.

## Применяемость

`source`: `manual`, `import` или `external_api`. Непроверенная строка имеет
`verified=false` и не должна использоваться как гарантия совместимости.
Значение `verified=true` допускается только после проверки ответственным
специалистом; тогда сохраняются `verified_at` и примечание.

LLM не создает и не подтверждает строки применяемости.
