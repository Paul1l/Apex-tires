# Справочник автомобилей и применяемость

## Что реализовано

В подборе по автомобилю пользователь выбирает:

1. марку;
2. модель;
3. год выпуска;
4. поколение или кузов при необходимости.

Марки и модели загружаются по API сайта, поэтому интерфейс не содержит
зашитый список из нескольких автомобилей:

- `GET /api/vehicles/makes` — марки легковых автомобилей, MPV и пикапов;
- `GET /api/vehicles/models?make=...&year=...` — модели марки для года;
- `GET /api/vehicles/generations?make=...&model=...&year=...` — поколения;
- `GET /api/v1/fitments/products?...` — UUID подходящих товаров.

В production все четыре запроса читают только проверенные записи PostgreSQL.
vPIC и региональный список используются исключительно в явно обозначенном
preview-режиме и не определяют совместимость товаров.

Марки и модели всегда показываются по алфавиту. Числа в названии учитываются
естественным образом: например, `A4` отображается раньше `A10`. При вводе букв
выпадающий список сразу оставляет только подходящие варианты.

## Важное разделение данных

Справочник автомобилей и таблица применяемости — разные сущности.

- Справочник отвечает на вопрос: «существует ли такая марка и модель?»
- Применяемость отвечает на вопрос: «какой конкретно товар подходит этой
  машине, году и поколению?»

Сайт не вычисляет совместимость по догадке. Если проверенных строк нет, поиск
возвращает пустой результат и предлагает форму «Не нашли автомобиль?». Заявка
сохраняется в PostgreSQL.

## Откуда брать точную применяемость

Рабочие данные должны поступать из 1С или лицензированного отраслевого каталога,
который уже используется компанией. Для каждого товара передаются марка,
модель, поколение, диапазон годов и признак заводской комплектации.

Метод импорта:

```http
POST /api/integrations/1c/v1/fitments/batch
```

Для ручной загрузки предусмотрен защищённый CSV endpoint
`POST /api/admin/imports/fitments` и шаблон
`docs/examples/fitments-import.csv`.

Один пакет полностью заменяет строки применяемости для затронутых товаров.
Товар должен быть предварительно загружен через `import/products`, а
`externalId` обязан совпадать со стабильным идентификатором номенклатуры в 1С.

## Ограничения справочника

Для автомобилей с 1995 года модели запрашиваются с учетом года. Для более
старых автомобилей внешний источник возвращает общий список моделей марки.
Клиент может фильтровать варианты вводом букв, но для запуска подбора обязан
выбрать марку и модель из списка. Это не позволяет сохранить опечатку как
автомобиль.

Профессиональный каталог применяемости нужен до публичного запуска. Без него
нельзя обещать автоматическую стопроцентную совместимость шин и дисков.
