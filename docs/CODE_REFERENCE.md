# Справочник кода

Имена в проекте описывают бизнес-смысл. Ниже перечислены компоненты и функции,
которые будущий разработчик будет чаще всего менять.

## Витрина

| Функция/компонент | Что делает |
| --- | --- |
| `Storefront` | хранит состояние фильтров и открытых панелей, рассчитывает выдачу каталога и собирает главную SPA |
| `ProductArt` | показывает загруженное фото или безопасную декоративную заглушку |
| `ProductCard` | отображает товар и действия с корзиной, избранным и сравнением |
| `Overlay` | общая доступная подложка модальных окон; закрывает окно по Escape и клику снаружи |
| `AuthModal` | двухшаговый вход/регистрация по email-коду с отдельными согласиями |
| `CartDrawer` | рассчитывает строки и итог корзины, проверяет принятие оферты и согласие на ПД |
| `QuickView` | быстрый просмотр характеристик товара |
| `AccountPanel` | данные текущего пользователя и ссылка в админку для разрешенной роли |
| `CollectionDrawer` | список избранного или сравнения |

Фильтрация выполняется в `useMemo` внутри `Storefront`: вид товара, сезон,
бренд, размер, цена, наличие, RunFlat, шипы, автомобиль и строка поиска
применяются последовательно; затем используется выбранная сортировка.

## Автомобильный справочник

| Функция/метод | Что делает |
| --- | --- |
| `GET /api/vehicles/makes` | объединяет официальный справочник марок с региональным резервом |
| `GET /api/vehicles/models` | возвращает модели выбранной марки с учетом года |
| `sortVehicleMakes` | сортирует все марки автомобиля по алфавиту |
| `sortVehicleModels` | сортирует модели выбранной марки по алфавиту с учетом чисел в названии |
| `getSupplementalModelsForMake` | возвращает российские и региональные модели при отсутствии во внешнем источнике |
| `SearchableVehicleSelect` | открывает прокручиваемый список марок/моделей и фильтрует его по введенным буквам |
| `updateSelectedCarBrand` | нормализует выбранную подсказку и сбрасывает зависимые поля |
| `updateSelectedCarYear` | меняет год и повторно загружает список моделей |

Подробности и граница между справочником и точной применяемостью описаны в
`docs/VEHICLE_CATALOG.md`.

## Состояние SPA

| Функция | Что делает |
| --- | --- |
| `StoreProvider` | предоставляет React Context каталога, серверного профиля, корзины, избранного и сравнения |
| `useStore` | возвращает Context и сообщает понятную ошибку при использовании вне provider |
| `readBrowserStorage` | безопасно читает JSON из localStorage и возвращает fallback при поврежденных данных |
| `addToCart` | создает строку корзины или увеличивает количество до восьми |
| `setCartQuantity` | меняет количество либо удаляет строку при нуле |
| `toggleFavorite` | добавляет или удаляет ID избранного |
| `toggleCompare` | добавляет или удаляет ID; хранит максимум четыре товара |
| `authenticateUser` | принимает безопасный профиль после успешного серверного OTP |
| `login` | показывает честный статус до подключения защищенной admin-аутентификации |
| `saveProduct` | обновляет товар по ID либо добавляет новый |
| `deleteProduct` | удаляет товар и связанные локальные строки корзины |

## Cookie и Метрика

| Функция | Что делает |
| --- | --- |
| `PrivacyTools` | читает выбор, показывает баннер/настройки и передает разрешение аналитике |
| `YandexMetrika` | получает runtime ID, выставляет флаг запрета и загружает тег только после согласия |
| `readCookieConsentPreferences` | проверяет версию и структуру сохраненного выбора |
| `saveCookieConsentPreferences` | сохраняет выбор с UTC-временем и отправляет событие обновления |

| `readYandexMetrikaCounterId` | читает и валидирует числовой ID из server environment |
| `GET /api/public-config` | возвращает клиенту только разрешенные публичные настройки |

## Правовые страницы

`legalDocuments` — единый типизированный массив текстов. `legalDocumentBySlug`
дает быстрый доступ по URL. `generateStaticParams` заранее создает все страницы,
а `generateMetadata` формирует отдельные title/description.

При добавлении документа нужно добавить один объект в `legalDocuments`: URL,
карточка индекса и статическая страница появятся автоматически.
